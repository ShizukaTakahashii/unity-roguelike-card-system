# Unity Roguelike Card Game System

This is a Unity-based roguelike card game prototype with cyberpunk and post-apocalyptic themes. The project focuses on card-driven combat, character progression, enemy encounters, event selection, and persistent game state management.

## My Role

I designed and implemented the core gameplay systems, including:

- Card data structure and card UI display
- Turn-based combat logic
- Enemy behavior and enemy data management
- Combat log system
- Character selection system
- Global save and reset logic
- Audio management
- Event-driven game flow

## Tech Stack

- Unity
- C#
- Unity UI
- ScriptableObject-based data design
- Data-driven gameplay configuration
